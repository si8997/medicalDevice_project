# RA Portfolio — 의료기기 QMS 절차서 교육

뇌혈전 제거술용 마이크로카테터(4등급)를 대상으로 작성한 5개 QMS 절차서와 관련 양식, 발표 영상, 시험문제, 참고자료를 한곳에서 보는 웹앱입니다.
서버나 DB 없이 **GitHub Pages**에서 동작하며, 내용은 모두 `data.xlsx` 엑셀 파일에서 읽어 옵니다.

- 사이트 주소: https://si8997.github.io/medicalDevice_project/

## 다루는 절차서

| 분야 | 절차서 | ISO 13485:2016 관련 조항 |
|---|---|---|
| 위험 관리 | QP-71-01 위험관리 절차서 | 4.1.2 b), 7.1, 4.2.5 |
| 공급업체 관리 | QP-74-01 공급업체 관리 절차서 | 7.4.1, 7.4.2, 7.4.3, 4.1.5 |
| 멸균 공정 밸리데이션 | QP-757-01 EO 멸균 공정 밸리데이션 절차서 | 7.5.7, 7.5.5, 7.5.6 |
| CAPA | QP-85-01 시정 및 예방조치 절차서 | 8.5.2, 8.5.3, 8.3.3, 8.4 |
| UDI 관리 | QP-758-01 UDI 절차서 | 7.5.8, 7.5.9.1, 4.2.5 |

## 주요 기능

- **포트폴리오 소개**: 품목(마이크로카테터) 선정 이유와 5개 학습 주제의 선정 이유
- **분야별 화면**: 상단 메뉴에 마우스를 올리면 하위 항목이 펼쳐집니다.
  - **절차서·양식**: 문서번호와 문서명, PDF 미리보기·새 창 열기, 형식별(DOCX / XLSX / PDF) 다운로드
  - **비디오**: 발표 영상을 버튼을 눌러 페이지 안에서 재생
  - **시험**: 분야별 객관식·주관식 문제. 객관식은 자동 채점, 주관식은 모범답안을 보고 직접 확인합니다. 결과는 저장하지 않습니다.
  - **참고자료**: 분야와 관련된 규격·링크
- **전체 보기**: 5개 분야의 같은 항목(예: 시험)을 한 화면에 모아 봅니다.
- **참고자료 페이지**: 참고 웹사이트(미리보기 카드)와 유용한 영상(페이지 안에서 재생, YouTube 바로가기)
- 휴대폰 화면 지원(☰ 메뉴)

│   ├── 002. 관련 양식/

각 폴더에는 원본(docx / xlsx)과 열람용 PDF가 같은 폴더에 함께 들어 있습니다.

## 내용 수정 방법

화면에 나오는 내용은 **`data.xlsx`만 고치면** 바뀝니다. `index.html`은 수정하지 않아도 됩니다.

| 시트 | 내용 | 열 |
|---|---|---|
| 설정 | 사이트 제목, 첫 화면 문구 | 항목, 값 |
| 소개 | 포트폴리오 소개 페이지 | 항목, 연결 분야, 요약, 본문 |
| 자료 | 절차서·양식·부적합 사례·비디오 목록 | 분야, 구분, 제목, 보기파일(PDF), 원본파일 |
| 시험문제 | 분야별 시험문제 | 분야, 번호, 유형, 문제, 보기1~4, 정답, 해설 |
| 참고자료 | 규격·사이트·영상 링크 | 분야, 구분, 제목, URL, 설명, 출처, 썸네일 |

작성 규칙:

- **시트 이름과 1행(제목 행)은 바꾸지 않습니다.**
- **파일 경로**는 `index.html` 위치 기준이며 폴더 구분은 `/`를 씁니다. 폴더나 파일 이름을 바꾸면 경로도 함께 바꿔야 합니다.
- **제목**에 `(QP-74-01-F01)`처럼 괄호로 문서번호를 붙이면 화면에서 문서번호가 제목 위에 따로 표시됩니다.
- **보기파일(PDF)**을 입력하면 미리보기·새 창·PDF 다운로드 버튼이, **원본파일**을 입력하면 해당 형식의 다운로드 버튼이 생깁니다.
- **시험문제 정답**: 객관식은 정답 보기 번호(1~4), 주관식은 모범답안을 적습니다.
- **소개 시트**: 연결 분야를 비우면 맨 위 큰 항목(품목 선정 이유)으로, 분야 이름을 적으면 주제별 항목으로 표시됩니다. 본문 셀 안의 줄바꿈(Alt+Enter)은 문단으로 나뉩니다.
- **참고자료 시트**: 분야를 `공통`으로 적으면 상단 메뉴의 참고자료 페이지에, 분야 이름을 적으면 해당 분야의 참고자료 탭에 표시됩니다. 썸네일 칸을 비우면 자동(영상은 YouTube 썸네일, 사이트는 사이트 아이콘)으로 표시됩니다.
- 상단 메뉴의 분야 순서는 자료 시트에 처음 나오는 순서를 따릅니다.

## 업데이트 방법

1. `data.xlsx`를 수정하거나, 새 문서를 해당 폴더에 넣고 `data.xlsx`에 경로를 추가합니다.
2. GitHub 저장소에서 **Add file → Upload files**로 바뀐 파일을 올리고 **Commit changes**를 누릅니다.
3. **Actions** 탭의 "pages build and deployment"가 완료되면(보통 1~2분) 사이트에 반영됩니다.

GitHub 웹 화면에서는 파일당 25MB까지 올릴 수 있습니다.

## 사용 기술

| 구분 | 내용 |
|---|---|
| 언어 | HTML, CSS, JavaScript (모두 `index.html` 한 파일) |
| 엑셀 읽기 | [SheetJS](https://sheetjs.com/) 0.18.5 (cdnjs) |
| 아이콘 | [Font Awesome](https://fontawesome.com/) 6.5.1 (cdnjs) |
| 글꼴 | IBM Plex Sans KR (Google Fonts) |
| 호스팅 | GitHub Pages (`main` 브랜치, `/ (root)`) |

첫 화면 배경은 이미지 파일이 아니라 코드(SVG)로 그린 그래픽입니다.

## 참고 사항

- **PC에서 `index.html`을 더블클릭해 열면 동작하지 않습니다.** 브라우저 보안 때문에 `data.xlsx`를 읽을 수 없으므로, GitHub Pages 주소로 접속해야 합니다.
- 엑셀 읽기·아이콘·글꼴을 인터넷에서 불러오므로, 외부 사이트가 차단된 네트워크에서는 화면이 정상적으로 보이지 않을 수 있습니다.
- 공개 저장소이므로 사이트와 모든 파일(시험 정답이 들어 있는 `data.xlsx` 포함)을 누구나 볼 수 있습니다.
- 페이지 안 영상 재생은 게시자가 외부 재생을 허용한 경우에만 됩니다. 허용하지 않은 영상은 "YouTube에서 보기"로 시청합니다.
